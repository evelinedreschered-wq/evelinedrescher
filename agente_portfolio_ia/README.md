# Assistente de IA para Portfólio Profissional

## 1. Visão geral

Este projeto tem como objetivo desenvolver uma assistente virtual com inteligência artificial integrada ao meu portfólio profissional, capaz de responder perguntas sobre meu currículo, minha trajetória profissional, minhas competências técnicas e meus projetos.

A proposta é facilitar o acesso às informações profissionais por meio de uma interface conversacional, proporcionando uma experiência interativa para recrutadores e visitantes.

## 2. Objetivos

- Desenvolver uma aplicação de inteligência artificial utilizando Python.
- Criar uma base de conhecimento estruturada sobre meu perfil profissional.
- Permitir consultas em linguagem natural sobre meu currículo e meus projetos.
- Integrar a assistente ao meu portfólio online.
- Avaliar a qualidade, a precisão e a confiabilidade das respostas.

## 3. Tecnologias previstas

- **Python:** desenvolvimento da lógica e do backend da aplicação.
- **HTML, CSS e JavaScript:** construção da interface conversacional.
- **Git e GitHub:** versionamento, documentação e publicação do código.
- **Modelo de linguagem (LLM):** geração de respostas a partir das perguntas dos usuários.
- **Serviços de hospedagem gratuitos:** publicação da aplicação, conforme disponibilidade e limites dos planos.

## 4. Arquitetura do projeto

O projeto será organizado em três componentes principais:

- `backend/`: lógica da aplicação e processamento das perguntas.
- `frontend/`: interface visual e interação com os visitantes.
- `conhecimento/`: informações estruturadas sobre currículo, competências e projetos.

## 5. Etapas de desenvolvimento

1. Preparação do ambiente e estruturação do projeto.
2. Organização da base de conhecimento profissional.
3. Desenvolvimento do backend em Python.
4. Integração com um modelo de inteligência artificial.
5. Criação da interface conversacional.
6. Integração ao portfólio online.
7. Testes, avaliação das respostas e documentação final.

## 6. Qualidade e confiabilidade

A assistente será desenvolvida para utilizar informações verificáveis sobre meu perfil profissional, evitar afirmações sem fundamento e informar quando não houver dados suficientes para responder a uma pergunta.
